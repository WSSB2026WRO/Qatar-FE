### 2026 — Finding the best model on the EV3

**Who:** Eissa, Omar, Mohammed

**What we wanted to do:** Make the EV3 robot reliable on the track.

**Our biggest problem:** The size of the robot and the steering angle. The robot has to be small enough for the rules and the parking space, but it still needs to turn sharply enough in the corners.

**What we did:** We took a lot of measurements on the robot and changed the design step by step. Each version was a bit better than the one before, until we reached the model we use now.

**The camera:** We tried different options for seeing the pillars. The camera we use now gave the best results of everything we tested.

### 2026 — Python vs EV3 blocks

**Who:** Omar (programming), with Eissa and Mohammed

**What we wanted to do:** Compare the two ways of programming the EV3, so we wrote both challenges in Python (Pybricks) and in EV3 blocks.

**What happened:** With Python, getting the robot ready and running took too long. The whole process went over the 90-minute limit in the rules.

**What we decided:** We switched to EV3 blocks for the competition, even though they are more complicated to write and organise for a program this big. We kept the Python versions in the repository because they show our logic clearly and helped us compare.

---

### Late 2025 – 2026 — First robot: Raspberry Pi 5 + ESP32

**Who:** Eissa, Omar, Mohammed

**What we wanted to do:** Build our car with a Raspberry Pi 5, a Pi Camera, and an ESP32 board to control the motors.

**What happened:** We spent a long time on this robot. The biggest problem was starting the program with the start button: the program did not launch reliably by itself (auto-run). In a competition, the robot must start with one button press, so this was a serious problem.

**What we decided:** We moved to the LEGO EV3. It starts programs reliably from its own button. It was hard to leave so much work behind, but it was the right choice.
